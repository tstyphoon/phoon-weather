# Discord Server 設定步驟

目標：建立你自己的 Discord Server、一個給 agent 用的頻道、拿到 `CHANNEL_ID`，並邀請同組同學加入。

名詞：
- **Server（伺服器）**：Discord 裡一個獨立的聊天空間，像一棟大樓。
- **頻道**：Server 裡的一個聊天室，像大樓裡的一個房間。agent 只會聽你指定的那一個頻道。
- **CHANNEL_ID**：頻道的身分證號碼，一長串數字。agent 靠它知道要聽哪一個頻道。

以下用 Windows 的 Discord 桌面版說明。網頁版（discord.com/app）畫面相同。

---

## A. 建立你自己的 Server

1. 打開 Discord 並登入。
2. 看畫面**最左邊那一排**圓形圖示（Server 列表）。拉到最下面，點那個**綠色的 `+` 圖示**（「新增伺服器」）。
3. 跳出視窗後，點最上面的 **「自己創建」**（Create My Own）。
4. 下一個畫面問「這個伺服器是給誰用的？」，點 **「只供我和我的朋友使用」**（For me and my friends）。
5. 在「伺服器名稱」欄位輸入名稱，例如 `phoon-weather 測試`。
6. 點右下角的 **「創建」**（Create）。
7. 完成後，最左邊那一排會多出你的 Server 圖示，你已經在裡面了。

---

## B. 建立給 agent 用的頻道

新 Server 通常已經有一個 `#一般` 頻道。**建議另外建一個專用的**，這樣日後測試不會混進一般聊天。

1. 在畫面**左邊第二欄**（頻道列表）找到「文字頻道」這個標題。
2. 把滑鼠移到「文字頻道」那一行，右邊會出現一個 **`+`**，點它。
3. 在「頻道類型」選 **「文字」**（Text），不要選語音。
4. 「頻道名稱」輸入 `天氣助理`（或英文 `weather`）。
5. **「私人頻道」的開關保持關閉**（關閉比較簡單；之後同學才看得到）。
6. 點右下角 **「創建頻道」**。
7. 左邊頻道列表會出現 `# 天氣助理`，點進去就是這個頻道。

---

## C. 拿到 CHANNEL_ID

要先打開「開發者模式」，Discord 才會顯示複製 ID 的選項。

### C-1. 打開開發者模式
1. 點畫面**左下角、你的頭像旁邊的齒輪圖示**（使用者設定）。
2. 在左邊選單往下找，點 **「進階」**（Advanced）。
3. 把 **「開發者模式」**（Developer Mode）的開關**打開**（變成綠色）。
4. 按右上角的 **ESC** 或 **X** 離開設定。

### C-2. 複製頻道 ID
1. 在左邊頻道列表，對 `# 天氣助理` **按滑鼠右鍵**。
2. 在跳出的選單最下面，點 **「複製頻道 ID」**（Copy Channel ID）。
3. 打開 **記事本**（開始選單搜尋「記事本」），按 **Ctrl + V** 貼上。你會看到一長串數字，像 `1234567890123456789`。
4. 先留著，之後要放進 `.env` 檔的 `CHANNEL_ID=` 後面（見 `discord-bot-setup.md` 最後一節）。

> CHANNEL_ID 不是機密，貼給別人沒關係。但沒有必要就不要到處貼。

---

## D. 產生邀請連結，讓同組同學加入

1. 對 `# 天氣助理` 這個頻道**按滑鼠右鍵**，點 **「邀請他人」**（Invite People）。
   （也可以對最左邊的 Server 圖示按右鍵，選「邀請其他人」。）
2. 跳出的視窗下方有一行連結，像 `https://discord.gg/xxxxxxx`。
3. 在視窗最下面點 **「編輯邀請連結」**（Edit invite link，一個小齒輪），預設有效期限只有 7 天，需要調整：
   - **「過期時間」**（Expire after）選 **「永不」**（Never）。
   - **「使用次數上限」**（Max number of uses）選 **「無限制」**（No limit）。
   - **「授予臨時成員資格」**（Grant temporary membership）**保持關閉**，否則同學離線後會被踢出去。
4. 按 **「產生新連結」**（Generate a New Link）。
5. 點 **「複製」**（Copy），把連結傳給同組同學（在你們的群組或私訊，不要公開貼到大型公開頻道）。
6. 同學點連結、按「接受邀請」就加入了。

### 邀請連結的注意事項
- 連結拿到的人都可以加入，**只傳給你信任的同學**。
- 如果之後想停用，回到「邀請他人」視窗，或到 **Server 名稱 → 伺服器設定 → 邀請**，把連結刪掉。
- 同學加入後，你可以到 `# 天氣助理` 頻道，請他們傳圖片測試。

## 完成確認

- [ ] 最左邊有你的 Server 圖示
- [ ] 有一個文字頻道 `# 天氣助理`
- [ ] 你已經把頻道 ID 貼在記事本裡（一長串數字）
- [ ] 同學用邀請連結可以進得來
